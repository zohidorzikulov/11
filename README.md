# QueryLab — PostgreSQL interaktiv laboratoriya

O‘zbek tilidagi amaliy SQL o‘quv platformasi.

## Ishga tushirish
\`\`\`bash
npm install
npm start
\`\`\`
Server \`PORT\` muhit o‘zgaruvchisidan foydalanadi.

## Imkoniyatlar
- PostgreSQL sintaksisiga yaqin SQL playground (pg-mem in-memory sandbox).
- Xatolik xabarlari va mavjud bo‘lsa pozitsiya/ustun ko‘rsatkichlari.
- SELECT, JOIN, GROUP BY, filtrlash va boshqa mavzularda 12 dars.
- Mashqlar, SQL qo‘llanma va ma’lumotlar sxemasi.
- Responsive premium interfeys.

## Muhim
Bu o‘quv sandboxi \`pg-mem\` yordamida jarayon ichida ishlaydi; to‘liq PostgreSQL serveri emas. Ma’lumotlar servis qayta ishga tushganda tiklanadi. Har bir brauzer sessiyasi uchun alohida vaqtinchalik sandbox yaratiladi.
